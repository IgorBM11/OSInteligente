# OS Inteligente · Proposta Starbridge para a Opy Health

Site estático da proposta de ordens de serviço com IA para a Manutenção Predial.

## Publicar no GitHub Pages

1. Crie um repositório na organização (ex.: `proposta_opy_os_inteligente`).
2. Suba todo o conteúdo desta pasta na raiz do repositório (`index.html`, `assets/`, `.nojekyll`).
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. O site fica em `https://starbridge-company.github.io/proposta_opy_os_inteligente/`.

## Estrutura

```
index.html          página completa (HTML, CSS e JS)
assets/             logos da Starbridge e da Opy Health
.nojekyll           publica os arquivos sem processamento do Jekyll
```
